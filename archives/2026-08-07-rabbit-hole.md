## 🧠 The Great Agent-Skills Land Rush

Look at GitHub trending today and you'd think "skills" are the new résumé. Four repos are converging on the same idea: instead of prompting an LLM to "be a senior engineer," you hand it a folder of battle-tested skills.

- **[addyosmani/agent-skills](https://github.com/addyosmani/agent-skills)** — Production-grade engineering skills for AI coding agents. The editor of *Chrome DevTools* is writing the playbook for how agents run tests, read logs, and merge PRs.
- **[mattpocock/skills](https://github.com/mattpocock/skills)** — "Skills for Real Engineers. Straight from my .agents directory." Matt is the TypeScript guy, so expect surgical precision.
- **[obra/superpowers](https://github.com/obra/superpowers)** — An agentic skills framework *and* a software development methodology. Less "here's a skill" and more "here's how your whole team should work."
- **[PrimeIntellect-ai/prime-agent](https://github.com/PrimeIntellect-ai/prime-agent)** — A self-improving RLM agent for coding workflows and long-running autonomous tasks. RLM = "Recursive Language Model"? Either way, it improves itself. What could go wrong?

And then there's **[cloudflare/computer](https://github.com/cloudflare/computer)** — "Give your agent a computer 👾" Because if you give an agent a skill, it can write code. If you give it a computer, it can redecorate your cloud bill.

**Takeaway:** The new CV might literally be a directory of `.md` files that teach an agent how you work. Your "10 years of experience" becomes a skills folder. Update your dotfiles accordingly.

## 🛠️ Useful Tools You Might Have Missed

- **[jdx/mise](https://github.com/jdx/mise)** — dev tools, env vars, task runner. It's `asdf` + `direnv` + a Makefile replacement in one Rust binary. If you're tired of juggling three version managers and a task runner, this is the calm center of your dev environment.
- **[goauthentik/authentik](https://github.com/goauthentik/authentik)** — "The authentication glue you need." Self-hosted identity provider for everything: SSO, LDAP, OAuth2, and more. When Keycloak feels like a dragon and proprietary auth feels like a cage, authentik is the bridge.
- **[chenyme/grok2api](https://github.com/chenyme/grok2api)** — Multi-account API gateway for Grok Build, Grok Web, and Grok Console. Want to prototype against Grok without committing to per-token costs? This folds multiple accounts into one API endpoint.
- **[schroedinger-Hat/certo](https://github.com/schroedinger-Hat/certo)** (Show HN) — Open-source infrastructure for issuing, managing, verifying, and exchanging digital credentials. Implements Open Badges 3.0 and W3C Verifiable Credentials. If you need to issue degrees, certifications, or "I finished this tutorial" badges without a commercial issuer, this is your infrastructure.
