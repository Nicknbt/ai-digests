## Trending GitHub Repos

**[cactus-compute/needle](https://github.com/cactus-compute/needle)**  
14MB foundation model for tiny devices: phones, wearables, smart home, robots. Yes — *MB*, not GB. That's not a typo. The "can it run on a smart lamp?" era has arrived.

**[cathrynlavery/diagram-design](https://github.com/cathrynlavery/diagram-design)**  
29 editorial diagram types for Claude Code, self-contained HTML + SVG. "No shadows, no Mermaid-slop." If you've ever winced at default Mermaid output, this is the palette cleanser you needed.

**[megadose/holehe](https://github.com/megadose/holehe)**  
Check whether an email is used on sites like Twitter, Instagram, and more — via the forgotten-password function. Useful for OSINT, privacy audits, and a creeping sense of how much of your identity is scattered across the internet.

**[smicallef/spiderfoot](https://github.com/smicallef/spiderfoot)**  
Automated OSINT for threat intelligence and attack-surface mapping. Pair with holehe for a fun afternoon of "wait, that account still exists?"

**[citrolabs/ego-lite](https://github.com/citrolabs/ego-lite)**  
"The fastest browser for AI agents" — share your logged-in browser state with Codex or Claude Code without being disturbed. Zero cost, zero config. Either that's magical or the start of a sci-fi movie.

**[macro-inc/macro](https://github.com/macro-inc/macro)**  
A unified workspace for teams: email, chat, docs, tasks, agents, calls, CRM — all @-linked with shared AI memory. It's like if Notion and a CRM had a baby that swallowed your inbox.

**[holaboss-ai/holaOS](https://github.com/holaboss-ai/holaOS)**  
Open-source "all-in-one AI agent workspace": run any agent across 100+ integrations, MCP, browser, files — with shared memory. Essentially an operating system for your agents.

**[github/spec-kit](https://github.com/github/spec-kit)**  
GitHub's toolkit for getting started with Spec-Driven Development. Because writing specs before code is apparently making a comeback — this time with ✨tooling✨.

**[lightningpixel/modly](https://github.com/lightningpixel/modly)**  
Generate 3D models from images or prompts using local AI, entirely on your GPU. Your graphics card is about to become a tiny 3D factory.

**[infiniflow/ragflow](https://github.com/infiniflow/ragflow)**  
A leading open-source RAG engine that fuses retrieval with agent capabilities. If your RAG pipeline feels like duct tape and prayers, this might be the proper context layer you've been missing.
